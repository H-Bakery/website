# api-sales-analytics

This library contains the sales analytics module for the bakery API.

## Features

- Sales transaction tracking
- Transaction item management
- Daily sales report aggregation
- Integration with product catalog

## Models

- `SalesTransaction` - Individual sales transactions
- `TransactionItem` - Items within a transaction
- `DailySalesReport` - Aggregated daily sales metrics

## Running unit tests

Run `nx test api-sales-analytics` to execute the unit tests via [Jest](https://jestjs.io).
