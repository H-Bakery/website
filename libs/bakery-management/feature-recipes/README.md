# feature-recipes

This library contains the recipe management functionality for the bakery management system.

## Features

- Recipe creation and editing
- Recipe listing and viewing
- Recipe form validation
- Recipe search and filtering

## Components

- `RecipeForm` - Form for creating and editing recipes
- `RecipeList` - Display list of recipes
- `RecipeDetailView` - Detailed view of a single recipe

## Testing

Run tests with:

```bash
nx test feature-recipes
```
