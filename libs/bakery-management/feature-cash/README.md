# feature-cash

This library contains the cash management functionality for the bakery management system.

## Features

- Daily cash entry recording
- Cash entry editing and history
- Monthly summaries
- Cash entry validation

## Components

- `CashEntryForm` - Form for recording daily cash entries
- `EditCashEntryModal` - Modal for editing existing cash entries
- `CashHistoryTable` - Display cash entry history

## Testing

Run tests with:

```bash
nx test feature-cash
```
