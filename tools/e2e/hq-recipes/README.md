# Synthetische Rezepte (E2E, Tests, lokale Entwicklung)

Erfundene Rezepte im Format von `hq/data/recipes/` - je Formatvariante mindestens eine Datei.
Namen, Mengen und Texte sind frei erfunden und ergeben kein backbares Rezept; nichts hier stammt
aus `hq` oder `backup_data`. Was die Dateien abdecken, steht in `docs/domains/rezepte.md`
(„Formate“).

Prettier fasst das Verzeichnis nicht an (`.prettierignore`): Leerzeichen am Zeilenende,
Tabellenbreiten und das fehlende Zeilenende am Schluss gehören zum Format.
