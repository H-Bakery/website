# Terminology Guidelines

## Business Areas

| German Term          | English Term   | Description                             |
| -------------------- | -------------- | --------------------------------------- |
| **Bäckerei Heusser** | Heusser Bakery | The entire business organization        |
| **Backstube**        | Bakery Kitchen | Production area where baking happens    |
| **Verkaufsbereich**  | Sales Area     | Retail shop where products are sold     |
| **Verwaltung**       | Administration | Management and administrative functions |

## Personnel Terms

| German Term          | English Term | Role Description                      |
| -------------------- | ------------ | ------------------------------------- |
| **Bäckermeister**    | Master Baker | Production staff who oversee baking   |
| **Verkaufspersonal** | Sales Staff  | Employees who work in the retail area |
| **Geschäftsführung** | Management   | Administrative leadership             |

## Process Terminology

| German Term            | English Term       | Context                          |
| ---------------------- | ------------------ | -------------------------------- |
| **Produktionsprozess** | Production Process | Workflows used in baking         |
| **Teigvorbereitung**   | Dough Preparation  | First stage of production        |
| **Backvorgang**        | Baking Process     | Main baking stage                |
| **Bestellliste**       | Baking List        | Daily production requirements    |
| **Verkaufsbericht**    | Sales Report       | Analytics from retail operations |
